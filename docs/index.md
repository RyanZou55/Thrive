# Thrive

一款记录植物（尤其仙人掌 / 块根）生长与浇水的 iOS App。

**亮点：帮你每次都从同一角度拍照。** 时间轴拉长之后，植物的变化会非常明显——而不是一堆角度各异、没法对比的照片。

## 怎么做到的

拍照时提供三重对齐辅助：

- **幽灵叠影** — 把上一张照片半透明叠在实时取景上，挪动手机让植株与虚影重合
- **姿态提示** — 读取手机的俯仰角和翻滚角，跟上次拍摄时的角度对比，对准了会轻震一下
- **构图网格** — 九宫格加可选参考框，帮你把花盆每次放在同一位置

## 还能做什么

- 为每株植物设定浇水间隔，到期当天早上提醒
- 记录品种、入手日期，时间轴上直接显示「第 N 天」

## 支持

Thrive 不收集任何数据，所有内容只存在你自己的手机上。详见[隐私政策](privacy-policy)。
