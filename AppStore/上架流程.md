照着往下做就行。分两部分：先在自己手机上验证，再走上架流程。

前提：手机 iOS 17 或更新（`IPHONEOS_DEPLOYMENT_TARGET = 17.0`）。签名已经配好了，
Team `3Z47RGMC36`，Bundle ID `com.ryanzou.thrive`，不用再动。

# 第一部分：装到自己手机上

## 1. 连线并选中你的手机

数据线连上 iPhone，手机上如果弹「信任此电脑？」点信任。

回到 Xcode，窗口顶部中间那个设备选择器（写着 iPhone 17 Pro 之类的），
点开，在最上面的 **iOS Device** 分组里选你自己的手机。

## 2. 按 ⌘R

第一次会编译一两分钟，然后自动装到手机上。

**如果报 "Unable to install"**：手机没解锁，或者没点信任。解锁手机再来一次。

## 3. 手机上信任开发者

第一次装会提示「不受信任的开发者」，App 图标点不开。

手机上：**设置 → 通用 → VPN与设备管理 → 开发者 App → 点你的账号 → 信任**。

回桌面点开 Thrive。

> 免费账号签的 App 7 天过期，你是付费账号，一年有效，不用反复重装。

## A. 拍第一张生长照 ⚠️ 关键

进任意植物 → **拍生长照** → 允许相机权限。

- [ ] 取景框有实时画面
- [ ] 九宫格看得见；点右上角两个按钮能开关网格和参考框
- [ ] 按快门能拍上，出现「这张留下吗？」确认页

> **重要：第一张必须用相机拍，不能从相册选。**
> 姿态数据是快门按下那一刻从陀螺仪读的，从相册选的图没有这个数据，
> 后面的姿态提示就不会出现。

## B. 拍第二张 —— 幽灵叠影 ⚠️ 从没验证过

同一株植物再点 **拍生长照**。

- [ ] 取景框上叠着上一张照片的半透明影子
- [ ] 拖底部的「叠影」滑块，虚影能从透明到明显
- [ ] 挪动手机时，能靠虚影把植株挪回原来的位置

**要特别留意的**：虚影和实时画面的裁切范围对不对得上。
照片是 4:3，屏幕是 19.5:9，两者都按「填满裁切」显示——理论上裁法一致，
但这是只有真机能验的事。如果虚影明显比实时画面大一圈或小一圈、或者位置偏了，
截图发我，我来修。

## C. 姿态提示 ⚠️ 从没验证过

前提是 A 步的第一张是用相机拍的。

# 第三部分：上架流程

验证都过了再往下走。

## 1. 把仓库设为 public，再开 GitHub Pages（一次性）

Apple 强制要求隐私政策网址。私有仓库开 Pages 需要付费方案，所以先公开仓库。

**先公开**：仓库 → Settings → General → 拉到最底部 Danger Zone →
Change repository visibility → Make public → 按提示输入仓库名确认。

**再开 Pages**：Settings → Pages → Source 选 `Deploy from a branch`
→ 分支选 `main`、目录选 `/docs` → Save。

等一两分钟，确认这四个地址都能打开：

- https://ryanzou55.github.io/Thrive/
- https://ryanzou55.github.io/Thrive/privacy-policy/
- https://ryanzou55.github.io/Thrive/en/
- https://ryanzou55.github.io/Thrive/privacy-policy-en/

## 2. 在 App Store Connect 建 App

[appstoreconnect.apple.com](https://appstoreconnect.apple.com) → 我的 App → `+` → 新建 App

| 字段 | 填 |
|------|-----|
| 平台 | iOS |
| 名称 | Thrive 植物生长记录 |
| 主要语言 | 简体中文 |
| 套装 ID | 选 `com.ryanzou.thrive`（已经注册好了） |
| SKU | `thrive-ios-001` |
| 用户访问权限 | 完全访问权限 |

## 3. 上传构建版本

Xcode 菜单 **Product → Archive**（设备选择器要选 "Any iOS Device"，不能选模拟器）。

打包完 Organizer 会自动弹出 → 选中刚才那个 archive → **Distribute App**
→ App Store Connect → Upload → 一路下一步。

传完等 10～30 分钟，App Store Connect 里才会出现这个版本（Apple 要处理）。

## 4. 填资料

照抄 [metadata.md](metadata.md)。里面已经按中英两份分好了，字数都核过。

先填简体中文那份，然后在页面左上角语言下拉里 **添加 English**，填英文那份。
两份的截图分别传 `screenshots/zh-Hans/` 和 `screenshots/en/`。

**App 隐私**问卷：全选「不收集数据」。Thrive 确实没有任何网络请求。

**年龄分级**：所有问题都选「无」，结果是 4+。

## 5. 提交审核

版本页面右上角 **提交以供审核**。

审核一般 1～3 天。被拒了把拒绝理由发我。
